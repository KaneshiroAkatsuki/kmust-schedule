# 玉衡山科学院

个人多功能空间：课表、资金规划、统一设置。当前前端版本 v3.5。

## 多功能入口与账户

- 课表保留现有课程管理、天气、日历及跨设备同步；网址不变。
- 资金规划为已核对 Excel 预算的私有只读看板，显示余额基准日期、月度收支、还款条目和月末余额预测。Excel 仍为主账本，更新后需受控导入预算快照；网页不自动读取电脑硬盘。
- 统一设置提供登录浏览器登记、备注、撤销，课表备份/回收站，预算导入/导出与本机减少动态效果选项。
- 一次登录共用账户；记住登录改用可撤销的随机凭据，不再持久保存新密码。网络/IP变化不作为浏览器身份依据。旧版已保存密码只用于首次升级登录，成功后清理。
- 浏览器会话由服务器登记和撤销；未记住登录有效期1天，记住登录有效期90天。撤销后下次联网检查失效，知道密码的用户仍可主动重新登录。
- 财务读取、导出与导入必须通过服务端会话校验，响应不缓存；真实财务数据不进入本仓库。旧课表的公开读取模式保持兼容，不应把财务数据混入课表接口。

资金规划后续由负责 Excel 更新的任务核对后直接发布，使用网站密码和 `scripts/publish-finance.mjs`，不依赖 Cloudflare 开发授权。具体步骤与失败处理见 [资金规划更新交接](docs/finance-publishing.md)。

部署顺序：先运行 `cloudflare-worker/migrations/0003_institute_sessions_finance.sql` 的增量迁移，再发布 Worker 与 Pages 网关，最后更新静态网页。迁移不会修改课表表；真实预算快照只导入私有后端。发布需要现有 Cloudflare 账户的有效授权。

2026-09-10 按用户要求在新 Cloudflare 账户重建服务，使用 `yuheng-institute-db`。课表按完整文档迁移，保留原修订号和修改时间；原云端资源未删除。新账户初始化需要先运行 `cloudflare-worker/schema.sql`，再运行会话/预算迁移。同步入口改变不影响下方 GitHub Pages 网页地址；已打开的旧页面需要刷新后连接新服务。

昆明理工大学呈贡校区研究生智能课表：实时课程状态、完整周课表、导师课提醒，以及电脑和手机之间的课表同步。

## 在线访问

- 网页：[https://kaneshiroakatsuki.github.io/kmust-schedule/](https://kaneshiroakatsuki.github.io/kmust-schedule/)
- 手机与网页同步入口：`https://yuheng-institute-gateway.pages.dev`
- 数据服务：`https://kmust-schedule-sync.yuheng-kaneshiro.workers.dev`（由同步入口转发，网页不再要求设备直接连接此域名）

网页使用统一登录入口。课表内置基础数据；财务模块没有公开兜底数据，登录或私有服务不可用时不会显示虚构余额。

课表以最新个人《课表打印》为基准，并额外保留明确要求参加的导师或带教教师课程。第2周为体验周，所有实际排课都会标注“体验课 · 必须参加”并进入“正在上课/下一节”提醒；第3周起，只有确认需要参加的课程进入提醒。计划撤销的课程在第3周保留显示一周并标注“待退选 · 无需上课”，第4周起登录后自动移入云端回收站。

## 天气更新

呈贡区天气由 Cloudflare Worker 每小时整点自动向百度地图天气更新，并保存到云端 D1；GitHub Actions 随后把经过校验的天气快照更新到本站 `data/weather.json`。手机和电脑优先读取这个同域文件，同域文件不可用时再通过 Pages 网关读取，不要求设备直接连接 `workers.dev`。即使所有设备都没有打开网页，两个定时任务仍会继续运行。天气入口位于首页数字时钟旁，点击后可查看当前指标、未来 24 小时和未来 7 日天气，也可以手动检查最新快照；接口临时失败时会保留上次成功结果并标注“缓存”。

## 管理课表

1. 打开网页并完成统一登录。
2. 在课表中点击课程卡片查看与修改，或使用“新增”；不需要重复登录。
3. 新增、编辑、删除或导入课程；分段授课可以填写多组周次和教师。
4. 点击“保存全部修改到云端”。

新增、编辑和 JSON 导入都会检查重复：同一星期、同一节次且周次重叠时，同名课程提示“重复课程”，不同课程提示“课程时间冲突”，并阻止保存。周次不重叠的分段课程仍可正常录入。

密码默认隐藏，不写入网页或仓库。“记住密码”是可选项，新版底层仅保存本浏览器可撤销的登录凭据；共用设备不要勾选。新会话仍会验证有效性，失效凭据会清除。保存使用修订号检查；另一台设备已有更新时，页面会阻止覆盖并要求重新载入。

课程表单先保存到“待同步列表”，再统一保存到云端。表单写到一半时关闭、切换课程、导入、导出或刷新都会提示；没有待保存修改时云端保存按钮会禁用。同一门课内部的教师分段若周次重叠也会被阻止，避免某一周匹配出两位教师。

## 技术结构

- `index.html`：前端结构、交互和19门次离线兜底课表（最新个人课表18门次，加1门李娜带教课程）。
- `assets/kust-lab-v2.css`：手机、折叠屏、笔记本和外接显示器共用的响应式视觉系统。
- `cloudflare-worker/`：Cloudflare Worker API 与 D1 数据库配置。
- `data/weather.json`：供手机同域读取的公开天气快照；由 `.github/workflows/weather-snapshot.yml` 每小时调用校验脚本自动更新。
- `test/frontend.test.mjs`：日期、课程、导师课、管理和响应式结构回归测试。

## 发布版本规则

每次发布页面改动时，必须同时更新 `index.html` 中的 `SITE_UPDATED_AT` 和 `SITE_VERSION`。当前版本从 `1.0` 开始，后续发布依次递增为 `1.1`、`1.2`、`1.3`……；同一次发布包含多个相关文件改动时只增加一次版本号。

本项目为个人整理工具，并非昆明理工大学官方系统。课程、教室和临时调课请以学院及任课教师最新通知为准。
