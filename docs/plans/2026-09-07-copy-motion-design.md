# KUST·Lab 3.2：文字与动效

沿用现有配色、布局和课程数据，优化日常阅读及操作反馈。

追加登录页设计：复用现有昆工校园照片与透明底校标。电脑采用校园照片与登录表单双栏，800 CSS 像素及以下改为上下布局；保留纯数字密码验证、默认隐藏密码、本机记住密码和云端登录流程。页面高度不足时允许完整滚动，不裁掉表单。

## 文字

- 去掉宣传语、拟人化安慰和重复的操作说明。
- 普通提示只说明当前状态或下一步；保留删除确认、未上传提醒和数据冲突警告。
- 不改变课程名、时间、周次、导师标记、既有账号和部署地址。

## 动效

- 采用短促、单次的过渡，不使用持续循环的天气或提醒动画。
- 按钮轻压反馈；弹窗、切换日期和编辑步骤轻微淡入。
- 时间和倒计时局部更新，相同内容不反复重建，减少闪动并保留焦点。
- 连续操作取消前一次过渡，不叠加动画；尊重系统的减少动态效果设置。
- 使用透明度和变换属性，不引入动画库或永久保留合成图层。

## 验证

自动测试覆盖提示语、单次动画、减少动态效果和渲染节点复用。使用本地模拟服务检查手机至桌面的交互，不向真实云端写入测试课程。不使用浏览器自动控制，不把 DOM 模拟作为实机流畅度证明。
