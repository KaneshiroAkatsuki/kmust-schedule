# KUST·Lab 云同步与校园极简 UI 设计

## 目标

把现有单文件课表升级为公开可查看、管理员可编辑、电脑与手机自动同步的个人课表。页面继续使用昆明理工大学透明校标和官方校园图，视觉方向采用暖白、石墨黑与昆工红的精致极简风格；所有课程、校历、导师课和实时状态逻辑保持可用。

## 页面结构

- 顶部使用独立白色导航栏，显示透明校标、`KUST·Lab` 和学年信息。
- 首屏保留校园图、当前时间、校历阶段和实时课程状态，但强化留白和信息层级。
- 今日课程与周课表使用大圆角白色内容面板；导师课使用昆工红提示。
- 周次按钮同时显示周数和日期范围；手机切周默认星期一，返回当前周恢复今天。
- 页脚采用苹果、华为官网常见的信息目录结构：桌面端三列，手机端折叠；底部保留数据来源、非官方说明和管理入口。

## 云同步架构

GitHub Pages 继续托管公开网页。Cloudflare Worker 提供公开读取和受保护写入接口，Cloudflare D1 保存完整课表快照、修订号和更新时间。网页内仍嵌入基础课表作为永久兜底；成功读取云端后切换到最新版，并把快照缓存在浏览器。云端不可达时使用最近一次缓存，不阻塞时钟和内置课表。

管理员在页脚打开“管理课表”，输入仅保存在当前浏览器会话中的管理密码，然后新增、编辑或删除课程。保存请求携带当前修订号；后端发现其他设备已经更新时返回冲突，前端要求先重新载入，避免覆盖较新的数据。

## 安全与边界

- 管理密码只保存在 Cloudflare Secret 和浏览器会话中，不写入 HTML、Git 或日志。
- Worker 限制允许的网页来源、请求体大小、课程数量、周次、时间格式和字符串长度。
- 公开接口只返回课表，不返回任何凭据。
- 手机与电脑看到的是同一份云端课表；同步可能受网络影响，但页面不会因此空白。

## 响应式策略

320px 起采用单列和全屏管理抽屉；折叠屏展开、笔记本和外接显示器使用内容驱动的双列布局。页脚目录在窄屏折叠、宽屏展开，不使用设备型号判断或固定分辨率适配。
