# Responsive holiday calendar implementation plan

**Goal:** Add a factual calendar below today's courses, inline on desktop and as a dedicated full-screen view opened by an icon entry on mobile.

**Architecture:** One calendar DOM and one date model; move the same component between its inline host and a native dialog at the existing 800px breakpoint. Use bundled official holiday data, with no extra API requests and no changes to courses, authentication or cloud data. Keep the same public URL.

**Tech Stack:** Existing inline JavaScript, CSS, Node test runner; local DOM simulation without browser automation.

## Design decisions

- A month grid is easier to scan than a holiday-only list; a separate desktop route would hide useful context. Desktop therefore gets the month grid directly below today's list.
- User requested a compact mobile icon entry and independent calendar page. At widths <=800px the entry opens an edge-to-edge, scrollable calendar view with a back button. Larger foldable viewports use the desktop layout.
- Monday-first, six stable rows, previous/next month, back to today, selected-date details. Today, selected date, holiday, makeup workday and ordinary weekend remain distinct by text as well as color.
- National makeup workdays do not assert a university makeup lesson. No course is moved, removed or hidden by this feature.
- Official source verified 2026-09-07: https://www.gov.cn/zhengce/content/202511/content_7047090.htm (State Council General Office, 2025-11-04).
- 2026 holidays: Jan 1–3, Feb 15–23, Apr 4–6, May 1–5, Jun 19–21, Sep 25–27, Oct 1–7. Makeup workdays: Jan 4, Feb 14/28, May 9, Sep 20, Oct 10. Years not bundled display an explicit unavailable-arrangements notice.
- China civil dates drive today and date rollover. Selected dates and browsing months survive background refresh, desktop/mobile switching and dialog closing.

2. Render the grid and selected-date detail without rerendering unchanged DOM. Add month, today and date controls with accessible names, pressed/current states and keyboard navigation.
