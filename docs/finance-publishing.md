# 资金规划更新交接

用户已要求：以后完成 Excel 预算更新后，同步更新网站预算，不再只交付工作簿。

## 数据与权限边界

- Excel 仍是主账本：先核对计算、版本和归档，再生成私有 JSON 快照。
- 快照保存在仓库外；真实金额、密码、令牌不进入公开 Git、交接文档或控制台输出。
- 日常预算更新只调用网站登录和预算接口，不使用 Cloudflare OAuth、不重新部署网页、不改变网页地址。
- 发布工具每次建立独立的一天期临时会话，用后撤销，不影响手机/电脑现有登录；不把设备身份绑定 IP。
- 不保存密码。网络、密码变更、服务暂停或授权被撤销仍可能使更新失败；不能承诺永久免授权或永久可用。

## 已核对快照的发布流程

工具：`scripts/publish-finance.mjs`，需要 Node.js 24，可选 `--use-env-proxy` 以沿用进程代理。无需安装依赖。

1. 先核算所有月度收支与明细、期初/期末滚动余额、锁定资金释放和分期归属。脚本校验结构与月度合计，不能代替 Excel 业务核算。
2. 用网站密码进行只读核对（隐藏输入，不能放在命令参数）：

   ```powershell
   node --use-env-proxy scripts/publish-finance.mjs '仓库外的快照绝对路径.json' --check
   ```

3. 记录输出的 `revision`。确认新版本高于云端，再执行发布，将下面的 `N` 替换为刚核对的修订号：

   ```powershell
   node --use-env-proxy scripts/publish-finance.mjs '仓库外的快照绝对路径.json' --publish --expected-revision=N
   ```

4. 必须同时看到 `status: published-and-verified` 和 `temporaryLoginRevoked: true` 才报告更新并读回核对成功。`already-current` 表示内容一致，无需写入，也不会伪造修改时间。
5. 冲突时重新核对，不能盲目换成新修订号覆盖。若上传发生后网络中断，先运行只读核对确认状态，不能把不确定结果说成“没有上传”。若临时会话撤销失败，到网页设置中检查并退出该记录。

发布成功后服务器自动更新预算的修改同步时间；电脑/手机在资金规划页每分钟读取一次，或点击更新。只改 Excel 文件不会自动触发网站更新，需要负责更新的任务执行上述步骤。

## 授权区别

- 网站已部署的课表、预算、天气不依赖这台电脑 Cloudflare CLI 的登录状态。
- Cloudflare OAuth 过期可能影响以后改服务代码、部署或管理资源；不妨碍凭有效网站密码发布预算。
- 普通未记住登录为一天，记住登录为九十天；失效或被撤销后需重新登录。网页保存的是可撤销凭据，不是明文密码。
- 更改网站密码、域名或 API 时，需要重新检查本工具；不要修改账户权限或购买服务来绕过失败。
